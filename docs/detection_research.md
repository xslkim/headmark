# 发际线手绘画线检测方案调研

> 调研日期：2026-06-11
> 测试数据：`test_image/`（input1.png / input3.JPG 为原图，output1.png / output3.png 为绿色描线真值）
> 实验脚本：`test_image/analyze.py`（像素级检测器对比）、`test_image/analyze2.py`（逐列 DP 曲线提取）、`test_image/analyze3.py`（端点锚定最小路径）

## 1. 任务定义

植发场景：医生在患者额头用记号笔画出规划的手术发际线。系统需要从正面人像照片中**检测出这条手绘画线**，生成闭合 mask 供扩散模型做头发生成。

画线的本质特征是三条：

1. **比局部周围皮肤更暗**（不是绝对的黑——笔迹深浅、光照、肤色都会变）；
2. **细长的线状结构**（宽度约为图宽的 0.3%~0.8%）；
3. **一条连续平滑的曲线**，从左鬓角弧形延伸到右鬓角，鬓角段接近垂直下降。

ROI 内的主要干扰源：**抬头纹**（同样是细暗线，且方向也近水平）、**眉毛**、**发丝/头发边缘**、**皮肤阴影**、痣。

## 2. 现有方案的问题（全局灰度阈值）

现实现（`processor.py` `_step4`）：在 ROI 内标记 `gray < threshold`（默认 115）的像素。

**实测根因：漏检是结构性的，不可调参解决。**统计两张测试图 GT 绿线带内的像素灰度：

| 图 | 画线带内平均灰度 | 默认阈值 |
|---|---|---|
| input1 | 127.6 ± 40.7 | 115 |
| input3 | 122.7 ± 43.9 | 115 |

笔迹像素的**平均**灰度高于阈值，即大部分笔迹根本不会被标记。调高阈值则皮肤阴影、眉毛大量误检——浅笔迹和深阴影在绝对灰度上是重叠分布，全局阈值无法分开。

## 3. 候选方案与实验结果

### 3.1 像素级检测器（实验1，`analyze.py`，结果图 `cmp_input1.jpg` / `cmp_input3.jpg`）

| 方案 | 原理 | 结果 |
|---|---|---|
| 全局阈值（现状） | `gray < T` | 漏检笔迹主体；阴影/眉毛误检；对光照极敏感 |
| 自适应阈值 | `cv2.adaptiveThreshold`，局部均值偏移 | 噪声非常多，毛孔、纹理全部触发，不可用 |
| **黑帽变换（推荐）** | `cv2.MORPH_BLACKHAT`，核 ≈ 图宽 2.5%，响应"比局部邻域暗的细结构" | **最优**。浅笔迹有局部反差所以不漏；大片平滑阴影不响应所以误检少 |
| Sato 脊线滤波 | `skimage.filters.sato(black_ridges=True)`，多尺度 | 与黑帽相近，但慢一个数量级，且对发丝响应更强 |

结论：黑帽变换是最佳的像素级响应图，但**单靠像素级检测不够**——抬头纹、眉毛、发丝边缘仍有响应，必须在曲线层面加约束。

### 3.2 曲线级提取（在黑帽响应图上）

**A. 逐列动态规划（实验2，`analyze2.py`，结果图 `dp_*.jpg`）**

每列选一行，最大化累计响应 + 相邻列平滑惩罚。

- 中段：中位误差 2px，抬头纹被平滑约束完全排除；
- **缺陷**：鬓角段画线近垂直下降，"每列一个点"的参数化无法表达，两端最大偏差 65px。不推荐。

**B. 端点锚定最小路径 / Dijkstra（实验3，`analyze3.py`，结果图 `dijkstra_*.jpg`）——推荐**

把黑帽响应取反作为代价图（响应越强代价越低），用 `skimage.graph.route_through_array`（`fully_connected=True, geometric=True`）求左右鬓角两锚点之间的最低代价路径。路径可以朝任意方向走，天然支持鬓角的陡降段。

| 图 | 平均误差 | 中位 | P95 | 最大 |
|---|---|---|---|---|
| input1 | 0.1px | 0.0px | 1.0px | 2.8px |
| input3 | 0.5px | 0.0px | 3.6px | 5.0px |

（误差 = 路径点到 GT 绿线带的距离变换值）两张图全程贴合真值，包括鬓角陡降段；抬头纹零干扰。

锚点来源：实验中用 GT 线两端模拟；生产中用 MediaPipe landmark `21`（左鬓角）和 `251`（右鬓角）附近位置，再在黑帽响应图上做局部吸附（小窗口内取响应最大点）。

### 3.3 颜色特征（辅助，未单独成方案)

统计了笔迹带 vs 周边皮肤的 Lab/HSV 分布，两者色度差异不稳定（笔迹带内混有皮肤像素、周边环带混有头发），**不建议把颜色作为主特征**；但若未来遇到蓝/紫色记号笔，可在代价图中加入色度项。

### 3.4 深度学习（后备方案）

轻量 U-Net 二值分割笔迹。优点：对笔色、光照、肤色最鲁棒。代价：需要 100~300 张标注（input/output 真值对正是现成的标注格式）、训练流程、PyTorch 部署（项目已有 head-segmentation 的子进程 PyTorch 基础设施可复用）。

**定位：经典方案在更大样本上暴露出难以修补的失败模式时再启动。**

## 4. 推荐落地方案

保留现有 1~3 步（landmark 上部区域 ∩ 头部分割 = ROI），替换第 4~5 步的检测核心：

1. ROI 内黑帽变换（核大小 = `max(15, int(w*0.025)|1)`）；
2. 左右锚点：landmark 21 / 251 → 响应图局部吸附；
3. `route_through_array` 求最小代价路径 = 画线；
4. 路径按笔迹宽度膨胀成线 mask，再与上方区域围成闭合 mask（contour / hull 下游逻辑沿用）。

纯 OpenCV + scikit-image，毫秒级，无训练、无新增重型依赖。

## 5. 已知风险

| 风险 | 缓解 |
|---|---|
| 样本只有 2 张，泛化未验证 | 在更多真实图上回归（不同笔色、极浅笔迹、深肤色、戴眼镜、刘海遮挡） |
| 照片里**没画线**时路径仍会被强行找出 | 拒识：路径上的平均黑帽响应低于阈值 → 判定"未检测到画线" |
| 画线紧贴发际线时，路径可能沿头发边缘走 | 用头部/头发分割结果在代价图中抑制头发区域响应 |
| 锚点 landmark 偏差大 | 局部吸附窗口 + 路径端部允许截断；极端时回退为响应图端点检测 |
